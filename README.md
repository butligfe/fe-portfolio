# Fe Butlig — Photography Portfolio

A responsive, dark-themed photography portfolio for Fe Butlig (BSCS 3A).

## Included
- `index.html` — portfolio content and page structure
- `style.css` — responsive dark visual theme
- `script.js` — mobile navigation and click-to-expand photo lightbox
- `assets/` — the three uploaded photographs used in the portfolio

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Keep the `assets` folder beside `index.html` so the photos load correctly.

No build tools or package installation are required. An internet connection is only needed to load the optional Google Fonts; system serif/sans-serif fallbacks are included.
